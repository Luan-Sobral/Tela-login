# 🔐 Tela de Login

Este é um projeto simples de uma tela de login responsiva, desenvolvida para praticar conceitos de HTML e CSS (e JavaScript, se aplicável). Ideal para portfólios ou como base para projetos maiores.<br>
<h2>🚀 Tecnologias Utilizadas</h2>
HTML5

CSS3 <br>
<h2>🎯 Funcionalidades</h2>
Interface moderna e responsiva

Campos de login e senha

Botão de acesso<br>

<h2>📦 Como Usar</h2>
</p>Clone o repositório:
https://github.com/Luan-Sobral/Tela-login.git 
</p>Abra o  arquivo index.html no navegador. <br>
